# Carnet d'Étoiles de Madeline

Page de révisions interactive et animée pour Madeline (CE2 → CM1), construite à partir de ses fiches de vacances : types de phrases, homophones, numération, fractions, problèmes de partage, grandeurs et mesures.

Chaque fiche est corrigée en direct pour les exercices fermés, et en autocorrection pour les phrases à inventer — avec le corrigé complet toujours disponible dans le "Coin des parents" en bas de page.

**Ouvrir la page :** activer GitHub Pages (Settings → Pages → Deploy from branch → main → /root) puis suivre le lien fourni par GitHub.
