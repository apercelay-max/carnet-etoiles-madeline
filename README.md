# Carnet d'Étoiles de Madeline

Page de révisions interactive et animée pour Madeline (CE2 → CM1) : huit fiches — rendre la monnaie, lire l'heure, la multiplication, la conjugaison, le compas, les longueurs, les masses et les contenances — chacune avec sa mascotte-chat, sa leçon et ses exercices du plus facile au plus difficile.

Chaque fiche est corrigée en direct pour les exercices fermés, et en autocorrection (avec un vrai compas et du papier) pour la fiche de géométrie — avec le corrigé complet toujours disponible dans le "Coin des parents" en bas de page.

**Ouvrir la page :** activer GitHub Pages (Settings → Pages → Deploy from branch → main → /root) puis suivre le lien fourni par GitHub.
